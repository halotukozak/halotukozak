Hi there.
I'm Bartek and I specialize in JVM languages, mainly **Scala** and **Kotlin**. 

I run a [blog](https://halotukozak.github.io) and like to contribute to the [scala 3 repo](https://github.com/scala/scala3/pulls?q=is%3Apr+author%3Ahalotukozak+)

You can check out the libraries I've made:
- [M&DE](https://github.com/halotukozak/made) - Mirror Annotations & Default Extraction. A Scala 3 macro library that extends `scala.deriving.Mirror` with annotation metadata, default values, generated members, and transparent wrapper support.
- [Alpaca](https://github.com/halotukozak/alpaca) - A type-safe lexer and parser library for Scala 3, featuring compile-time validation and a pattern-matching DSL.
- [mcodec](https://github.com/halotukozak/mcodec) - GenCodec-style serialization for Scala 3 — a format-agnostic, streaming Input/Output core with type class derivation built on `M&DE`. 
- [justworks](https://github.com/AVSystem/justworks) - A Gradle plugin that just works and generates type-safe Kotlin Ktor clients from OpenAPI specs
- [sure](https://github.com/halotukozak/sure) - Type-safe value validation DSL for Kotlin Multiplatform.
